# LifeGuard AI

## Overview
LifeGuard AI is an AI-powered preventive healthcare platform that predicts potential health risks using user health metrics and lifestyle data.

## Features
- Health Dashboard
- AI Risk Prediction
- BMI Calculator
- Disease Risk Analysis
- Voice Assistant
- Report Upload
- Personalized Recommendations

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Router
